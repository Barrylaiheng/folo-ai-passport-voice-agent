AI Passport 随身语音 · Agent 模式  v0.4.2
========================================

把 FoloToy AI Passport（巴掌大的语音小钥匙）变成 WorkBuddy / Trae 等 AI 应用的无线语音键：
按住设备上键说话 → 松开自动转写进聊天框 → 短按下键发送。

【三步上手】
1. 装好 VB-CABLE 虚拟声卡（官网 vb-audio.com/Cable，装完重启一次电脑）。
2. 双击本目录的 AI-Passport-Voice-v0.4.2.exe —— 无窗口，右下角出现托盘图标即成功。
3. 设备打开「AI语音」→ 点进 AI 应用聊天框 → 按住上键说话 → 松开出字 → 下键发送。

【本版本 v0.4.2 要点（跨机全自动，零配置零切换）】
- 语音跟随 DeskFlow 焦点：人用 DeskFlow 把键鼠切到哪台电脑，设备语音就落到哪台机，
  全程零操作——不配对、不切换、不碰托盘。焦点机不在线时自动兜底本机，永不哑按。
- 音频跟随推流：声音自动流向局域网内所有在线电脑，下线自动停，切屏零延迟。
- B 机助手注入改 keybd_event（VK 方式）：实测 WorkBuddy 录音键只认 VK 注入；
  注入前自动找回并激活 Agent 窗口，跨屏切过去按上键即录。
- 语音键与回车统一走焦点路由；配置文件丢失时自动回退出厂默认，不再空跑。

【配置（可选，已带出厂默认，开箱即用）】
编辑同目录的 voice-config.json：
- apps：要接入的 AI 应用及其语音快捷键（默认 WorkBuddy=ctrl+d / Trae CN=alt+v）。
- vban.target：留空 = 自动跟随（向所有在线机推流）；填 IP = 固定推给那台机。

【跨机使用 · 两台电脑（可选，全自动）】
1. 另一台电脑（B 机）解压本 zip，进 btrigger/ 子目录，双击 AI-Passport-btrigger-v0.4.2.exe
   （建议先右键 setup-bmachine.cmd 以管理员运行一次：自动放行防火墙 + 登录自启）。
2. B 机麦克风（系统设置 → 声音 → 输入）选 CABLE Output，前台打开 WorkBuddy 或 Trae。
3. 完成。之后人坐在哪台机前，按设备上键语音就落在哪台机——两边都不用任何切换。
详细见 docs/CROSS_MACHINE.zh-CN.md。

【排错】
托盘菜单 → 打开日志 看 forwarder.log（B 机助手日志在同目录 btrigger.log）。
安全软件（尤其火绒）可能把全局键盘钩子进程当键盘记录器周期强杀，
请把本目录加入信任区 / 排除项。
